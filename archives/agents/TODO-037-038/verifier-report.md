## 4. total-time-display の直書き無し

`total-time-display` を検索したところ、値は `initPlaylist()` からではなく
`recalcTimeline()` → `slideSpan(index)` → `slideData[index].duration` の
積み上げで `totalDurationSeconds` に入り、表示更新のコードから
反映される作りだった（`total-time-display` 自体への直書きは無い）。
コード読解のみで、実行しての確認はしていない（別途 `initPlaylist` 実行時に
表示更新されるコード経路までは追ったが、実際に UI の合計時間表示が
5:54 になっているのはスクリーンショット（pc_slide17.png、右下 `5:54`）
で確認できた。スライド4 + 17 の duration 変更後も UI 上は整合している
ように見える）。
