### 1. `CLAUDE.md:25` — 「`duration` は 1.4 倍速で読み切る実時間」は実測と合わない

```

```

逆算すると `duration` は約 10.6 文字/秒に相当するが、Google TTS の実測は

## 検討

### 5. `playbackRate` ≥ 1.5 では時間軸と読み上げがずれる（観点 2）

`fallbackAudioElement.playbackRate = Math.min(2.0, getEffectiveSpeed())`（1426 行）と
`utterance.rate = Math.min(2.0, getEffectiveSpeed() * 0.95)`（1364 行）に
上限 2.0 がある。`getEffectiveSpeed()` が 2.0 を超えるのは
`playbackRate > 1.43`、つまり `speedOptions`（1677 行）の **1.5 / 1.75 / 2.0 の 3 つ**。

この 3 つでは音声の速さが 2.0 倍で同じになるのに、時間軸（`deltaTime * playbackRate`）は
1.5 / 1.75 / 2.0 倍とそれぞれ違う速さで進む。スライド 1 で言うと:

| UI | 音声の実速度 | 音声の長さ | バー満了 | 止まる時間 |
|---|---|---|---|---|
| 1.0x | 1.4 | 18.1s | 12.0s | 6.1s |
| 1.5x | 2.0（上限） | 12.6s | 8.0s | 4.6s |
| 2.0x | 2.0（上限） | 12.6s | 6.0s | 6.6s |

1.5x と 2.0x は耳で聞こえる速さが同じなのに、バーの進み方だけが変わる。
`TODO.md` の「速度を上げれば読み上げも時間軸も同じだけ縮む」は
1.25x までしか成り立たない。上限そのものは変更前からあるが、
時間軸を「実時間」と位置づけた今回の変更で、食い違いが説明しにくくなった。

### 6. 再生中の速度切り替えでナレーションが頭から鳴り直す（観点 3、1680-1688 行）

```js
playbackRate = speedOptions[nextIdx];
...
if (isPlaying) {
    speakCurrentNarration();
}
```

`speakCurrentNarration()` は `stopSpeech()` してスライド先頭から読み直すが、
`currentSlideElapsedTime` は据え置き（リセットするのは `renderSlide(i, true)` の
1456 行だけ）。結果、**バーは途中のまま音声だけが頭に戻る**。
バーが既に `duration` で頭打ちなら、丸ごと 1 枚読み直す間ずっと 100% で止まる。

消音中に速度を切り替えた場合も同じで、`duration / playbackRate` の待ちが
最初から張り直され（1316 行）、そのスライドが延びる。

変更前からある挙動で今回の差分が原因ではないが、今回「時間軸を実時間に合わせる」
という位置づけにしたので、ここだけ辻褄が合わない。

### 7. スライド途中へのシークで音声が頭から鳴る（観点 3、1827-1836 行）

```js
currentSlideElapsedTime = targetSec - slideStartTimes[targetIndex];
renderSlide(targetIndex, false);
```

`renderSlide(..., false)` は `currentSlideElapsedTime` を保つが、その先の
`speakCurrentNarration()`（1475 行）はナレーションを先頭から読む。
スライドの 8 割の位置にシークしても、音声は頭から流れてバーだけが残り 2 割を進み、
すぐ頭打ちになる。

`targetSec` の基準は `totalDurationSeconds`（= `duration` の合計 214 秒）なので、
シークバーの目盛りは実際の上映時間（約 333 秒）に対応していない。
これも変更前からの挙動。今回の差分では悪化していない。

### 8. 消音中だけはバーと送りが完全に一致する（良い点の確認）

消音経路（1314-1320 行）は待ち `duration / playbackRate`、バーの進みも
`deltaTime * playbackRate` になったので、バーが 100% に届いた瞬間に
`onSlideAudioFinished()` が呼ばれる。ここは変更で正しくなった。
ただし `onSlideAudioFinished()` が更に 1 秒待つ（1301 行）ので、
1 枚につき 1 秒だけ 100% で止まる。消音での通しは 214 + 17 = 231 秒。
