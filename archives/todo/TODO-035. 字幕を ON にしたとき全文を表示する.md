## きっかけ

`#caption-text` に `line-clamp-2` が付いていて、字幕が 2 行で切られていた。
枠の高さが変わってよいので、ナレーションの全文を表示したい。

作業中に「PC でも字幕をスライドの下に出す」が加わった。全文にすると PC では
枠に重なる面積が増えるため。

## やったこと

`claude_memo.html` のみ。

- `#caption-text` から `line-clamp-2 overflow-hidden` を削除
- `#subtitle-banner` のクラスを `absolute bottom-3 left-4 right-4` から
  `mt-3` に変更し、画面幅によらず枠の下へ流す
- 重ね表示のための `#subtitle-banner { margin: 1px }` と、`@media` 内の
  `position: static` のルールを削除
- `#viewport-stage.is-fullscreen > #subtitle-banner`（`top: 100%`）を
  `@media` の外へ移し、全画面幅で共通にした

## 確かめたこと

verifier が Chromium ヘッドレスで `file://` から開き、実測した
（報告: `archives/agents/TODO-035/verifier-report.md`）。

- 最長のナレーションはスライド 6 の 176 文字。PC (1280x800)、横持ちスマホ
  (844x390)、縦持ちスマホ (390x844) のいずれでも字幕の `scrollHeight` と
  `clientHeight` が一致し、切れていない。修正前の複製では横持ちで
  `scrollHeight=96` / `clientHeight=48` と切れていた
- PC の通常表示で、スライド枠の下端 580.4 に対し字幕の上端 617.4、
  字幕の下端 741.4 に対しシークバーの上端 772.4。どこにも重なりが無い
- 横持ちスマホの通常表示は、字幕の上端が -51.3（画面の上へはみ出し、
  スクロールしないと読めない）から 121.8 に変わり、むしろ良くなった

## 残ること

擬似フルスクリーンでは、字幕が画面の下端からはみ出す（PC で 96px、
横持ちスマホで 184px。縦持ちスマホははみ出さない）。16:9 のレターボックスが
画面いっぱいに広がると、その下に字幕を置く余白が残らないため。

**はみ出したままでよいと決めた（2026-09-18）。** フルスクリーンは
スライドを見せるための表示で、字幕はその外という整理。

## 分担の振り返り

- verifier は、依頼した 6 点のうち擬似フルスクリーンのはみ出しだけを問題として
  挙げ、はみ出し量を px で示した。通常表示については修正前の複製を自分で作って
  比較し、「以前は確かに 2 行で切れていた」という根拠まで出した。
  依頼に「数値で示すこと」「たぶん大丈夫は不可」と書いた効果が出ている
- 見込みは implementer + verifier だったが、実際の変更は CSS とクラス属性の
  数行で、implementer を立てる必要が無かった。立てるときに「行数は小さいが
  レイアウトなので確認は要る」と読めていれば、見込みの段階で verifier のみに
  できた。字幕の見え方は 1 行の CSS でも画面サイズごとに結果が変わるので、
  確認を分ける判断自体は正しかった
- 次に同じ規模（CSS だけの表示調整）をやるなら、main が直して verifier だけを
  分ける。画面サイズと「何を数値で示すか」は依頼に先に書く。今回は
  途中で変更が増えたので、同じ verifier に追加の依頼を送って撮り直させた。
  立て直さずに済み、Playwright の準備をやり直さなくてよかった
