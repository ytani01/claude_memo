## やったこと

`archives/todo/` の 58 件のうち「分担の振り返り」を持つ **47 件**（800 行）を
読み、繰り返し出ているものを根拠の番号付きで並べた。

抜き出しは機械的に済ませた。

```bash
for f in archives/todo/*.md; do
  n=$(basename "$f" .md | cut -d. -f1)
  sec=$(awk '/^## 分担の振り返り/{f=1} f&&/^## /&&!/分担の振り返り/{f=0} f' "$f")
  if [ -n "$sec" ]; then echo "### $n"; echo "$sec" | grep -v "^## 分担の振り返り"; fi
done
```

62KB に収まったので、サブエージェントに要約させず main が直接読んだ。
**要約を挟むと「何件で出たか」が消える**ので、繰り返しを数える作業では
直接読むほうが精度が出る。
