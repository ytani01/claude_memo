Claude しか読まない場所に置いておくものではない。TODO-042 で
`docs/Usage.md`（スライドを作る人向け）を作ったので、同じ場所に
`docs/Developer.md`（`player.html` を直す人向け）を置くことにした。

- 移した内容は `CLAUDE.md` に**残さない**（二重管理にしない）
- TODO 番号の参照は**落とし、理由を本文に書く**
- Usage はスライドを作る人向け、Developer は `player.html` を直す人向けとし、
  相互にリンクする

## 分担の振り返り

- verifier が見つけたのは `margin: 1px` の 1 件。**移す作業そのものより、
  移す元が古くなっていたことのほうが問題だった**という、こちらが想定して
  いなかった指摘が出た。書いた本人は「元にあったものを写した」で疑わない
  ので、分けた意味があった
- 見込みとの食い違いは無し
- 依頼に「一致したものは 1 行、食い違いだけ詳しく」と書いた効果は出た。
  TODO-042 の報告より項目数が多いのに、verifier の料金は $0.2 → $0.3 で
  収まっている（照合対象は 3 倍近い）
- 次に**既存の文書を別ファイルへ移す**項目をやるなら、同じ形でよい。ただし
  依頼文に「**移す前の記述が現在の実装と合っているかも確かめる**」と明記する
  こと。今回は「移し漏れ」と「事実の照合」を別々に頼んだから拾えたが、
  「移し漏れの照合」だけを頼んでいたら、古い記述はそのまま通っていた
